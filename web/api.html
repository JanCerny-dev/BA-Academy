API lab

Send real HTTP requests from your browser and read the response, like in Postman. Two public APIs that need no key:

  • ARES – the official Czech business register (GET a company by its IČO). This is the kind of lookup an underwriter does manually today.
  • JSONPlaceholder – a fake REST API for practice; you can also try POST, PUT and DELETE (nothing is really saved).

Presets:

What to notice

  • The status code: 200 OK, 201 Created, 404 Not Found (try a non-existent IČO like 00000001), 400 Bad Request (try letters instead of digits).
  • The structure of the JSON: objects { }, arrays [ ], nested fields such as sidlo.nazevObce.
  • The time it took – non-functional requirements often say how fast an integration must answer.
  • Which fields you would map into the PolicyHub buyer record (module 11, exercise on field mapping).

Some APIs block calls from web pages (CORS). Postman does not have that limitation – use it for everything else.

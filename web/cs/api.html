API lab

Posílej skutečné HTTP požadavky z prohlížeče a čti odpověď, podobně jako v Postmanu. Dvě veřejná API bez klíče:

  • ARES – oficiální registr ekonomických subjektů (GET firmy podle IČO). Přesně takové dohledání dnes underwriter dělá ručně.
  • JSONPlaceholder – cvičné REST API; zkusit můžeš i POST, PUT a DELETE (nic se doopravdy neuloží).

Předvolby:

Čeho si všímat

  • Stavový kód: 200 OK, 201 Created, 404 Not Found (zkus neexistující IČO, např. 00000001), 400 Bad Request (zkus písmena místo číslic).
  • Strukturu JSONu: objekty { }, pole [ ], vnořená pole jako sidlo.nazevObce.
  • Dobu odpovědi – nefunkční požadavky často určují, jak rychle musí integrace odpovědět.
  • Která pole bys namapovala do záznamu odběratele v PolicyHubu (modul 11, cvičení na mapování polí).

Některá API volání z webových stránek blokují (CORS). Postman tohle omezení nemá – na ostatní API použij jeho.

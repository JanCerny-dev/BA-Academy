Tools to try

Everything a junior BA is expected to have touched. Most are free and run in the browser. Tick a tool once you have used it for a real exercise, not just opened it.

Company data stays at the company

Practise only with the fictional ExportShield data from this site. Never paste work or client data into public AI tools or personal accounts. At work, use the tools your IT has approved.

tools tried
  • bpmn.io demo Free · browser · no sign-up

    Draw BPMN 2.0 diagrams in the browser and download them as .bpmn or image. The fastest way to start modelling.

  • Camunda Modeler Free · desktop

    Desktop BPMN and DMN editor used in real automation projects. Try a DMN decision table for the pre-check rules.

  • draw.io (diagrams.net) Free · browser or desktop

    General diagramming: BPMN, UML, ER diagrams, flowcharts, wireframes. Many companies use it inside Confluence.

  • Mermaid Live Free · browser

    Diagrams written as text (sequence, ER, state, flowchart). Same syntax as the diagrams on this site; also supported in GitHub, GitLab and Confluence add-ons.

  • PlantUML online Free · browser

    UML from text. Common in technical documentation written by developers.

  • SQL lab (this site) Free · in this site

    SQLite in your browser with the ExportShield dataset. No installation, nothing leaves your computer.

  • SQLBolt Free · browser

    Short interactive SQL lessons with exercises. Good warm-up before the SQL module.

  • SQLite Online Free · browser

    Online SQL editor; paste the ExportShield script and query it in a tool that looks like a real database client.

  • API lab (this site) Free · in this site

    Send real GET/POST requests to ARES and JSONPlaceholder from the browser and read the JSON.

  • Postman Free plan

    The standard tool for calling and testing APIs. Testers and developers will expect you to know it.

  • JSONPlaceholder Free · no key

    A fake REST API for practising GET, POST, PUT and DELETE.

  • ARES API (Czech business register) Free · public · no key

    Real public API of the Ministry of Finance: look up a Czech company by its IČO. Used in the capstone.

  • JSONLint Free · browser

    Validate and format JSON. Use it whenever a payload "doesn't work".

  • Swagger Editor Free · browser

    Read and write OpenAPI specifications – the format vendors use to describe their APIs.

  • Jira & Confluence (Free plan) Free up to 10 users

    Backlogs, user stories, sprints and documentation. The most common tool pair in Czech IT teams.

  • Trello Free plan

    Simple Kanban boards – a gentle start before Jira.

  • Miro Free plan (limited boards)

    Online whiteboard for workshops, stakeholder maps, story mapping and fishbone diagrams.

  • Power Automate Needs a Microsoft work or school account

    Microsoft's low-code automation – the platform you are most likely to meet in Czech corporates. Use it only where your employer allows; otherwise practise in Make or n8n.

  • Power Apps Needs a Microsoft work or school account

    Low-code apps (forms, approvals) on top of SharePoint or Dataverse.

  • Make Free plan

    Visual automation platform with a free plan – the easiest place to build the capstone intake automation with your own account.

  • n8n Open source / cloud trial

    Open-source workflow automation, popular for AI automations. Similar concepts to Power Automate.

  • AI assistant (ChatGPT, Claude or Copilot) Free tiers

    Draft interview questions, user stories and test cases – then review them critically. Only fictional data, never company data.

Free reading and references

  • BABOK Guide overview (IIBA)

    The standard body of knowledge for business analysis. The overview is free; the full guide comes with IIBA membership.

  • The Scrum Guide (2020)

    The official 13-page definition of Scrum. Read it once in full.

  • BPMN 2.0 poster (PDF)

    All BPMN symbols on one page. Print it and keep it next to you while modelling.

  • Camunda BPMN primer

    Clear practical intro to BPMN from the people who make Camunda.

  • BPMN 2.0.2 specification (OMG)

    The official standard – for looking things up, not for reading cover to cover.

  • uml-diagrams.org

    Examples and explanations of every UML diagram type.

  • IREB CPRE Foundation Level syllabus v3.3.0 (PDF)

    Free, compact and rigorous summary of requirements engineering. Good reference even without the exam.

  • Atlassian Agile Coach

    Short articles on Scrum, Kanban, user stories, epics and estimation.

  • Postman Learning Center

    Official docs and tutorials for Postman.

  • ARES – information for developers (Czech)

    Official documentation of the ARES API, including a Swagger UI.

  • ČNB API (Swagger)

    Czech National Bank exchange-rate API in JSON – compare it with the plain-text daily rates file.

  • W3Schools SQL tutorial

    Quick reference with a try-it editor for every SQL command.

  • Microsoft Learn – Power Platform training

    Free official learning paths for Power Automate and Power Apps.

  • Power Apps Developer Plan (Microsoft Learn)

    Read the current conditions before you sign up – they change from 15 November 2026.

  • Modern Analyst – templates

    Free BA templates (requirements documents, use cases, checklists) to compare with your own.
